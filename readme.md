# FighterZone Taekwondo Academy

A practice landing page for a example Taekwondo academy, built to work through real-world layout, accessibility, and interaction patterns.

🔗 **Live site:** https://himanshiagrawal21.github.io/Project/

## About
## About

My coach asked me to build a website for the academy. I didn't feel ready to take that on for real yet, so I used his request as the inspiration for this project instead — a chance to practice building a complete, production-style small-business page before eventually building the actual site for him.

## What I focused on

- Semantic HTML — proper landmarks, heading hierarchy, and meaningful element choices throughout
- Accessible navigation — a mobile menu with correct `aria-expanded`/`aria-controls` wiring, keyboard-reachable focus states, and a skip link
- Fluid typography and spacing using `clamp()`, so the layout scales smoothly across screen sizes without fixed breakpoints doing all the work
- BEM naming conventions for predictable, collision-free CSS
- A lightweight testimonial slider built in vanilla JavaScript, including resize handling and disabled states at the first/last slide

## Tech

- HTML5
- CSS3 (no framework — custom properties, Flexbox, Grid)
- Vanilla JavaScript (no libraries)

## Running locally

Clone the repo and open `index.html` in a browser — no build step required.
